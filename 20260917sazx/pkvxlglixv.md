# 【我为群众办实事】高风险！脑卒中气象风险橙色预警首发——天津医大二院气象与脑血管病研究团队提醒气温骤降要警惕脑卒中

昨日，我市发布寒潮黄色预警，同时天津市气象台与天津市健康气象交叉创新中心首次联合发布脑卒中气象风险橙色预警，提醒公众受11月6日至7日寒潮天气影响，天津地区气温骤降，诱发脑卒中的气象风险高。天津市健康气象交叉创新中心是由天津市科技局批准，天津医科大学第二医院、天津市气象局为双组长单位，联合南开大学、天津大学、浪潮集团、天津九安医疗电子股份有限公司共同建立的天津市第一个交叉创新中心。脑卒中气象风险预警为天津市健康气象交叉创新中心最新科研成果。

**气温骤降 关注脑卒中**

作为天津市健康气象交叉创新中心牵头单位之一，天津医科大学第二医院神经内科与老年病科气象与脑血管病研究团队，对近5年来在神经内科和老年病科住院的5730例急性脑梗死患者进行分析发现，随着月温差跨度的增大，脑梗死患者中的发病例数逐渐增多且有高血压病史的老年患者对温度变化更敏感。冬季日平均气温在-3.10℃与-0.90℃之间，冬季气温下降2.30℃以上、夏季气温上升2.10℃及以上，急性脑梗死发病增加。日平均气温低于2.8℃时脑梗死患者预后不良。面对寒潮天气，如何预防脑卒中风险发生？对此，天津医科大学第二医院副院长李新教授提醒：
1

//  注意保暖
出门前确认当日的温差情况，如果有大幅度降温，一定要准备好御寒用具。在寒冷的早晨，起床第一件事是穿上放在床边的外套，拖鞋和袜子也要穿，千万不要光着脚走在地板上。即使只是去外面拿报纸，最好也要围上围巾，戴上帽子。寒潮到来的日子里，能不出门尽量不出门，避免冷热刺激引起的血压大幅度波动。如果非得在冷天外出，一定要穿上足够的御寒衣物，尤其不要忘记戴围巾和手套。习惯晨练的老年朋友也要注意，最好不要很早就出来运动，在地表温度升高之后再到户外进行锻炼，最佳时间段为上午10点至下午3点，同时要做到劳逸结合, 以散步、打太极等舒缓项目为宜。
2

//  补充水分
成年人每日水的摄入量约为1500ml-2000ml（不包括食物中的水分），即使在出汗量不多的季节，血液还是可能因为气温的变化而变得粘稠，有效血容量出现了不足，就会进一步引起脑血管疾病的发生，所以，多补充水分是非常重要的。另外，有糖尿病的患者的血液粘稠度更高，所以必须补充更多的水分。
3

//  坚持服药
正在服用降血压和控制血脂等药物的人，每天都要按时服药，定期在家里测量血压，若血压波动较大或控制不佳时，及时到医院就诊，调整药物的使用。
