# 三五学雷锋 青年在行动

> 更新时间：2026-09-16 (UTC+8)

2021年“3·5”学雷锋纪念日，在院党委“党建引领、文化筑基、价值激励、人文服务”16字方针倡导下，深圳市第二人民医院团委进一步弘扬雷锋精神，组织开展了内容丰富的学雷锋活动。在志愿活动中，青年志愿者们立足本职、身体力行，把弘扬雷锋精神和传递医者正能量结合起来，发挥专业所长、践行医者仁心！

“三五学雷锋”系列活动之

“我是小小急救员”急救技能知识进校园
       3月2日，深圳市第二人民医院团委及志愿服务U站牵头，联合华新小学开展了针对在校师生的“我是小小急救员”急救技能知识讲座，活动得到了全校师生的广泛响应，共100余人参加了培训。参加此次活动的同学们都纷纷表示学到了很多在书本上学不到的知识。

       门急诊团支部书记彭刚刚护士长作为培训导师，结合生活中遇到的突发事情，讲解了心肺复苏、AED、伤口包扎、烧伤、溺水、鼻出血及异物梗阻等的急救方法。讲课生动有趣，同学们听得津津有味，问答环节同学们更是积极踊跃的发言。

      随后，指导老师对同学们进行了一对一的模拟训练，耐心纠正操作动作、解答各类疑惑。时间过得很快，近2个小时的培训课程在一片融洽的氛围中结束。通过培训，同学们提高了在日常学习和生活中对于意外事故、常见病症的应急能力，为自己和身边的人构筑了一道安全防线。

“三五学雷锋”系列活动之

“爱心车队、暖心的哥”进二院

       为学习和弘扬雷锋同志“全心全意为人民服务”精神，积极传递正能量，3月5日上午，市二医院联合华程交通集团举办了学雷锋做好事的爱心车队公益活动，为前来就医老幼患者、残障人士等送上温暖和关爱，让他们感受到春日的生机勃勃。

       上午9点，党委徐勇书记一行参加了启动仪式，20辆爱心的士准时整齐地停在了急诊科门前，他们接上就诊患者，往返于这座志愿之城，让红色“正能量”释放在城市中，让爱心车队成为鹏城一道流动的红色风景线。

“三五学雷锋”系列活动之

从院内做起，换角度体验医患关系

       3月5日，院团委联合规培党支部组织青年志愿者在门诊大厅、分诊台等多个服务点积极开展院内志愿服务活动。

       青年义工们主动热情接待病人，在大厅协助患者进行登记，引导患者前往正确就诊地点，为病人提供咨询帮助，维持电梯口秩序，给予老弱病残者适当帮助并陪同就诊，保持诊疗秩序和谐有序的进行。党委徐勇书记也在繁忙工作中出席了志愿服务活动，在第16届“深圳义工节”到来之际，为在站义工送上节日祝福。全院广大青年团员积极响应党委号召，发挥先锋队作用，弘扬志愿精神，到场团员志愿者共50余位，服务患者1000多人次。

       通过开展志愿服务活动，深圳市第二人民医院广大团员用实际行动践行初心使命，感染身边的人，营造一个和谐温馨的就医环境。参加活动的青年人纷纷表示，脱下白大褂，穿上红马甲，化身志愿者的一天，更能让我们感受到患者就医的心情和过程，重新审视自身，今后也将在临床工作中更加关注细节，以患者健康为中心，时刻为高水平医院建设做出应有贡献，为中国共产党成立100周年献礼！
